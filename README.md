## 關於這個 repo

這裡存放的是 **inline 打包後的部署版**（單一 HTML 檔，所有 CSS / JS 已內嵌），不是開發版原始碼。

開發版原始碼與設計文件放在 `Lumiture-ai`（private）：

| 項目 | 位置 |
|---|---|
| 開發版 HTML | `Lumiture-ai/prototypes/` |
| 設計規範 | `Lumiture-ai/guidelines/` |
| PRD / Specs | `Lumiture-ai/specs/` |
| 競品研究 | `Lumiture-ai/research/` |
